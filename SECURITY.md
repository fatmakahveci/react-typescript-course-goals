# Security Policy

## Supported Versions

Security updates are provided for the latest published minor version.

| Version | Supported |
| --- | --- |
| 1.1.x | Yes |
| < 1.1 | No |

## Reporting a Vulnerability

Do not open a public issue for a security vulnerability. Use [GitHub private vulnerability reporting](https://github.com/fatmakahveci/react-typescript-course-goals/security/advisories/new) instead.

Include a clear description, reproduction steps, affected versions, and potential impact. You can expect an initial response within seven days. Valid reports will be investigated, fixed, and disclosed responsibly.
